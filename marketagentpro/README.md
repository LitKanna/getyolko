# MarketAgentPro

MarketAgentPro is a modular, local-first Streamlit dashboard for US stock
research: watchlists, charts, technical signals, portfolio tracking, options
strategies, news, and AI-powered analyst summaries.

It runs fully locally. Market data can come from **yfinance** (no key needed)
or **Alpaca** (bring your own free API keys). AI summaries can use a local
**Ollama** model, or your own **OpenAI (GPT)** / **Anthropic (Claude)** API key.
No cloud account is required to try it.

> **Disclaimer:** This project is for research and reference only. It is not
> financial advice.

---

## Features

- **Dashboard** — multi-symbol charts (Today / 2 Days / Month / 52 Weeks),
  volume, EMA20/EMA50 + RSI (1H & Daily), risk levels, custom alerts, and an
  AI Analyst Brief that combines cached news with technicals.
- **Portfolio** — positions, transactions, P/L, alerts, and options strategy
  tracking with Alpaca option snapshots / chain picker.
- **News** — market-wide and per-stock news from Google News, cached locally,
  with optional AI translation and impact tagging.
- **AI Summary** — English / Chinese / Bilingual analyst briefs generated by a
  local Ollama model, or by OpenAI / Anthropic with your own key.
- **EXE packaging** — a one-file Windows executable can be built with
  PyInstaller (see [EXE_BUILD.md](EXE_BUILD.md)).

## Quick start (EXE)

1. Build once: `.\build_exe.ps1` (output: `dist\MarketAgentPro.exe`).
2. Double-click the EXE. It starts a local Streamlit server and opens the app
   in your default browser.
3. User data is stored in a `data` folder next to the EXE.

> If you distribute the EXE, delete `dist\.env` first — it may contain your own
> Alpaca keys.

## Configuration

### 1. Market data provider

Copy `.env.example` to `.env` and edit it:

```text
MARKET_DATA_PROVIDER=yfinance   # or alpaca
ALPACA_API_KEY=your_key
ALPACA_SECRET_KEY=your_secret
ALPACA_DATA_FEED=iex
```

- `yfinance` — candles and latest price; no API key needed.
- `alpaca` — latest quote/trade from Alpaca (free keys work with `iex`), with
  yfinance fallback. Historical chart candles still use yfinance.

Demo users do **not** need to edit `.env` for Alpaca: open the sidebar
**Alpaca / Market Data** panel, choose `Alpaca (my own keys)`, paste the key,
click **Test**, then **Save & Activate**. Keys are stored only in the local
`data` folder.

### 2. AI providers

The sidebar **AI Settings** panel supports four providers:

| Provider | How it works |
| --- | --- |
| `Off / No AI` | No LLM calls; rule-based summaries only. |
| `Ollama Local` | Uses a local Ollama model (default when a `.env` exists). |
| `OpenAI (GPT)` | Bring your own OpenAI API key. |
| `Anthropic (Claude)` | Bring your own Anthropic API key. |

In the panel, choose a provider, enter your API key / model (cloud providers),
click **Test AI**, then **Save AI**. Without a `.env`, users can enter their own
keys directly in the UI — nothing is uploaded; keys are saved in the local
`data` folder.

Relevant `.env` defaults:

```text
AI_PROVIDER=ollama
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=qwen2.5:14b

OPENAI_API_KEY=
OPENAI_MODEL=gpt-4o-mini
OPENAI_BASE_URL=https://api.openai.com/v1

ANTHROPIC_API_KEY=
ANTHROPIC_MODEL=claude-3-5-sonnet-latest
ANTHROPIC_BASE_URL=https://api.anthropic.com/v1
```

Additional AI behavior settings: `AI_LANGUAGE_MODE`, `DASHBOARD_AI_MODE`,
`AI_STREAMING`, `DASHBOARD_AI_MAX_NEWS_ITEMS`, `DASHBOARD_AI_OUTPUT_LENGTH`.

### 3. Data & privacy

- All settings, portfolio history, transactions, and news caches are stored
  locally under `data/` (gitignored, never committed).
- `.env` and `dist\.env` are gitignored and must never be committed.
- API keys entered in the app are stored in `data/marketagentpro_settings.json`
  on the local machine only.

## Project structure

```text
app.py                        Streamlit entry point
desktop_launcher.py           EXE launcher (starts Streamlit, opens browser)
build_exe.ps1 / *.spec        PyInstaller packaging
marketagent/
  config.py                   Env / .env defaults
  storage.py                  Local settings, portfolio profiles
  ai_agent.py                 AI provider layer (Ollama / OpenAI / Anthropic)
  market_data.py              Quote/chart/option fetch + caches
  providers/                  yfinance + Alpaca provider implementations
  pages/                      Dashboard / Portfolio / News pages
  ui/sidebar.py               Sidebar panels (watchlist, AI, Alpaca)
```
